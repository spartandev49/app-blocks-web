# Repository contribution policy

`app-blocks-web` is publicly readable and MIT-licensed, but the upstream repository is maintained exclusively by `spartandev49`.

- No outside account is granted direct write access.
- Unsolicited pull requests are not part of the upstream workflow and may be closed without review.
- Public forks and independent modifications remain permitted by the MIT license.
- Security defects should use the private process in [SECURITY.md](SECURITY.md), not a public exploit report.

This policy protects a single coherent language and release history. Public visibility does not imply shared repository control.
