# Changelog

All notable changes are documented here. The project follows semantic versioning once public releases begin.

## 0.1.0 — 2026-09-01

- Added the two-space-indented AppBlocks Web language.
- Added source-located parsing, typed values and strict validation.
- Added 81 block contracts across document, layout, navigation, content, marketing, reading and application families.
- Added dependency-free HTML, CSS and JavaScript compilation.
- Added responsive headers, heroes, sections, pricing, FAQ, dashboards, tables, forms, tabs, dialogs, charts, boards and feedback states.
- Added build, dev, validate, inspect, catalog and token CLI commands.
- Added four strict-compiling example projects and a self-hosted four-route showcase.
- Added exact byte-expansion benchmarks, tests, static security/accessibility audits and machine-readable schemas.
